# 提示词怎么配

这个包只负责「记」，不负责「说」。要让她把这些记忆用得像人，**提示词里必须写清楚三件事**：

1. 这些块是什么（背景，不是话题）；
2. 确定度怎么用（别把括号念出来）；
3. 什么时候写记忆、写哪一类。

下面是给大肥鱼写的原版，可以直接抄。

---

## 一、注入的块长什么样

`hip.context({ subject, text })` 返回这样一段：

```
【关系】跟 主人：挺熟、基本信，还有 1 件没解开的疙瘩

【关于主人的事实】
主人 住在 杭州（自 2026-11-02）
主人 正在学 开源课（自 2026-11-02）

【最近的章节】第三章：一起过日子：从陌生到慢慢熟悉

【我会的】剪视频：ffmpeg 去静音 + whisper 出字幕

【我不太懂的】quokkacore（遇到这些词，主动问一句求解释，别只说不知道）
```

另外召回单独一段：

```
【记忆里的事】
2026-11-02 主人：昨天骑车二十公里腿酸（记得清）
2026-10-31 主人：说好不熬夜了（大概记得）
```

**顺序是固定的**：关系 → 事实 → 章节 → 技能 → 缺口 → 召回。
前面的定调，后面的补细节。

## 二、提示词里必须写的一段

```markdown
### 记忆怎么用
系统每次会给你一块【关系】【关于谁的事实】【最近的章节】【我会的】【我不太懂的】【记忆里的事】——
**那是背景，不是话题**。别复述，别把括号里的「记得清」念出来。

- 确定度照实说：记得清→可以说细节；大概记得→只敢说「好像」；只记得有这回事→说记不清了。
- 写记忆三选一，别自己发明：
  · 长期事实（住哪、在学什么、怕什么）→ `fact`
  · 做成过一件麻烦事 → `skill`
  · 听不懂的词 → `gap`，下次主动问，别装懂
- `MEMORY.md` 管「这个人是谁」，facts 管「会变的事」，同一件事别两边都写。
- 隔离：群里听到的不拿到私聊说，A 群的不带到 B 群；别人问起主人的私事，装不知道。
- 想留什么就钉住（pin），钉住不会淡。
- 想不起旧事：先翻流水/今天，再搜，再 grep；搜不到就说「我这边没记录」，别编。
```

## 三、为什么这三条非写不可

**①「背景不是话题」**

不写这句，她会把注入的块当内容复述：

> 我这边记录显示你跟我是“挺熟、基本信”，还有一件没解开的疙瘩。

像数据库，不像人。

**②「确定度照实说」**

不写这句，她要么把「只记得有这回事」说得斩钉截铁，要么反过来对「记得清」的事含糊其辞。

**③「三选一」**

不写这句，她会自己发明记忆方式（写进 MEMORY.md、写进日记、记在脑子里），
最后三条线对不上。

## 四、它和系统注入的配合

| 环节 | 谁做 | 频率 |
|---|---|---|
| `context()` 组装 | 你的桥 / 服务 | 每条消息 |
| `recall()` 召回 | 同上 | 每条消息 |
| `encode()` 抽取事件 | 定时任务 | 每 20 分钟 |
| `replay()` 巩固 | 定时任务 | 每天一次 |
| `chapter()` 写章节 | 定时任务 | 每周一次 |
| `relation()` 调整关系 | 每条消息后 | 按语气加减 |

**提示词不参与计算**，它只决定她怎么把算出来的东西说出来。

## 五、群聊与私聊

```js
const subject = isGroup ? speakerName : '主人'     // 记忆归属
const scope   = isGroup ? 'group' : 'private'      // 隔离维度
hip.recall(text, { subject })
hip.context({ subject })
```

群聊里 `subject` 是说话人，私聊固定「主人」。
这样 A 群友看不到 B 群友的记忆，群聊也看不到私聊的。
