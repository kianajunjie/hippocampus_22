# 实测数据

全部可复现。原始结果在 `bench/results/`。

## 一、长期召回（模拟 90 天 × 3 组随机）

每 3 天埋一件事，每天 1–3 条噪音，每 10 天巩固一次；提问用与原文不同的说法。

| seed | 埋点 | recall@1 | 误召 |
|---|---|---|---|
| 1 | 31 | 21 | 0 |
| 7 | 32 | 13 | 0 |
| 42 | 34 | 25 | 0 |
| **均值** | — | **61%** | **0** |

## 二、消融（90 天，seed 7）

| 配置 | recall@1 | 60 天以上旧事 | 情绪比 |
|---|---|---|---|
| 完整 | **13/32** | **27%** | 1.98x |
| 关掉情绪权重 | 7/32 | **9%** | 1.28x |
| 关掉关联边 | 13/32 | 27% | 1.98x |
| 忘得更快 | 7/32 | 9% | 1.92x |

**结论**：情绪权重让旧记忆存活率变成 3 倍；边不影响字面召回，只帮主题召回。

## 三、遗忘是真的

默认 `base 0.95` + `minStrength 0.1`：

```
中性记忆（情绪 0）   ≈ 45 天后召回不到
情绪记忆（±2）       ≈ 7 个月后消失
```

没有这个门槛，记忆只会重排、不会消失。

## 四、长间隔不误合并

同一主题相隔 70 天：合并后仍是 2 条（`mergeWindowDays: 7` 生效）。

## 五、密集事实抽取（LLM）

两轮对话各埋 3 个事实：抽出 6 条，6 个探测全部命中。

## 六、分层叠加（每层值不值）

种一份已知记忆，问 7 个只有对应层能答的问题，逐层打开：

| 配置 | 答对 | 平均 tokens |
|---|---|---|
| 只有人设 | 0/7 | 46 |
| ① 事件 | 1/7 | 71 |
| ② +事实 | 3/7 | 108 |
| ③ +关系 | 4/7 | 133 |
| ④ +章节 | 5/7 | 149 |
| ⑤ +技能 | 6/7 | 174 |
| ⑥ +缺口 | **7/7** | 198 |

单层去掉：事实 −2，关系/章节/技能/缺口/事件 各 −1。**没有一层是白加的。**

**缺口层的坑**：第一版去掉它不掉分——因为注入时没写“该主动问”。
补上之后，同一层从 0 收益变成 +1。**层有用，也要写清怎么用。**

## 七、已知盲区

```
事实：主人骑车二十公里腿酸
问「腿还疼不疼」     → 命中
问「运动之后的肌肉疼」 → 词法 0 命中（查询改写后可命中）
```

纯词法检索，换个完全不同的说法会漏；接 `embedder` 可补。
