# hippocampus_22

陪伴型机器人（QQ / IM / 网页 / Telegram）的**情感记忆层**：事件编码 → 巩固 → 遗忘 →
联想 → 元记忆，五个环节照着人脑的海马体抄，不是一个向量库套壳。

> 派生自 [dsh-hippocampus](https://github.com/kianajunjie/dsh-hippocampus) v0.3.1（MIT），
> 保留其记忆内核，并在本项目上继续演进。派生说明见 [NOTICE](NOTICE)。

```bash
npm i hippocampus-22
```

## 快速看一眼（不需要模型、不需要 API Key）

```bash
node cli.mjs demo
```

## 能做什么

- **事件记忆**：把对话变成「谁、何时、发生了什么、什么情绪」
- **情绪加权遗忘**：被感动的记得久，日常的忘得快
- **确定度**：记得清 / 大概记得 / 只记得有这回事
- **改口即失效**：你改主意了，旧记忆自动作废
- **关系层**：亲密、信任、没解开的疙瘩
- **事实 / 章节 / 技能 / 缺口**：住哪、哪阵子、怎么做事、什么不懂
- **按人隔离**：A 看不到 B 的记忆，群聊看不到私聊
- **零依赖**：Node 内置 SQLite，一个本地文件就是全部记忆

## 结构

```
              QQ 桥 / im / 网页 / 别的软件
                          │
                   identities 表（同一人 = 一个 subject）
                          │
        ┌─────────────────┴─────────────────┐
        │            handleTurn()           │
        │  解析身份 → 组装 context → 召回   │
        └─────────────────┬─────────────────┘
                          │
   ┌──────────┬───────────┼───────────┬──────────┐
 events     relations    facts      chapters   skills / gaps
 事件       关系         事实        章节       技能 / 缺口
   └──────────┴───────────┴───────────┴──────────┘
                          │
                  context() → 提示词块
```
